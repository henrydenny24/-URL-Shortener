# URL Shortener

A simple URL Shortener web application built using Python, Flask, and SQLite.

This project converts long URLs into short and easy-to-share links.

## Features

- Shorten long URLs
- Generate unique short codes
- Redirect short URLs to the original URL
- Store URLs in SQLite
- Simple and clean web interface
- Basic URL management

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
